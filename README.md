# Jivam

Jivam is an Electron-based application built with React, TypeScript, and Vite. It provides a chat interface with AI agents, file browsing, and persona management.

## Features
- Multi‑panel chat UI with AI agents
- File browser and preview
- Persona management and customizable settings
- Electron packaging for Windows and macOS

## Development
```bash
# Install dependencies
npm install

# Run in development mode
npm run dev

# Build the production bundle
npm run build
```
